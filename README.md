# HIL Biomedicals & Systems Ltd (Ghana)
## Digital Health & Biomedical Engineering Portfolio Codebase

Welcome to the official repository and source code package for **HIL Biomedicals & Systems Ltd** (Accra, Ghana). This project delivers a unified digital portfolio, an 8-page corporate brochure, and a single-page corporate e-card/flyer, bridging the gap between hospital clinical software and biomedical hardware.

### 🏥 Solutions & Modules Covered

#### 1. Software & Digital Health Division
- **EMR (Electronic Medical Records):** Clinical documentation, longitudinal patient records, electronic prescriptions, vitals tracking.
- **HMIS (Hospital Management Information System):** Patient registration, appointment scheduling, billing/cashiering, NHIS integration, ward bed management.
- **RIS & PACS (Radiology Information & Picture Archiving):** DICOM 3.0 viewer, cloud/local PACS archive, radiologist reporting workflows.
- **LIMS (Laboratory Information Management System):** Sample accessioning, barcoding, automated analyzer interfacing (ASTM/HL7), PDF diagnostic reports.
- **HFMS (Hospital Financial Management System):** General ledger, departmental revenue auditing, NHIS claims reconciliation.
- **SFMS (Smart Facility Management System):** Preventive maintenance scheduling, biomedical equipment calibration tracking, breakdown ticketing.
- **EMS (Enterprise Medical Suite):** Multi-branch hospital consolidation, executive BI dashboards, centralized analytics.

#### 2. Medical Equipment & Biomedical Engineering Division
- **Medical Imaging:** Digital X-ray systems, multi-slice CT scanners, diagnostic ultrasound, C-arms.
- **Critical Care & ICU:** ICU ventilators, multi-parameter patient monitors, infusion/syringe pumps, defibrillators.
- **Surgical & Operating Theater:** Electrosurgical units, LED operating lights, hydraulic operating tables, anesthesia workstations.
- **Clinical Laboratory Equipment:** Fully automated biochemistry analyzers, 5-part hematology analyzers, centrifuges, incubators.
- **Biomedical Services:** Equipment calibration, planned preventive maintenance (PPM), and emergency repairs across Ghana and West Africa.

### 🚀 How to Run & Inspect Locally

This project is built using modern, pure **HTML5, CSS3, and Vanilla JavaScript (ES6)**:
- **No Node.js or build steps required.**
- **No external server or database setup needed** to inspect the user interface.
- To run:
  1. Clone or extract this repository.
  2. Double-click `index.html` (or `brochure.html` / `hil_biomedicals_ecard.html`) to open directly in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

---

### 🌐 Live Deployment via GitHub Pages

This repository is configured for deployment via **GitHub Pages**:
1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select branch `main` and folder `/ (root)`, then click **Save**.
4. The live site will be accessible at: `https://noasido.github.io/hil-biomedicals-portfolio/`.
